# Steal a Dragon Egg

A 3D steal-and-run browser game: sneak into a sleeping dragon's cave, grab eggs from its
golden hoard and carry them to your nest before it wakes up and breathes fire.

**Play:** https://kam-karma.github.io/steal-a-dragon-egg/

## Run locally

```
npm install
npm run dev      # http://localhost:5183
npm test
npm run build    # output in dist/
```

Built with three.js, Vite and TypeScript. Every push to `main` is built and published to
GitHub Pages by `.github/workflows/pages.yml`.
